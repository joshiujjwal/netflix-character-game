# Feature Specification — netflix-character-game

**Version:** 0.1 (pre-implementation)  
**Last Updated:** Phase 0  
**Status:** Draft

---

## 1. Overview

### Problem Statement
Fans of movies and TV shows have no interactive, AI-powered trivia experience that adapts to their knowledge level in real time. Static quiz apps go stale quickly and don't personalize difficulty. This game closes that gap.

### Core Value Proposition
- Fresh questions every session, generated by GPT-4o from live TMDB data
- Difficulty adapts per player — you're never bored or overwhelmed
- Shared daily challenge creates community and replayability
- Works beautifully on mobile (the primary gaming device)

---

## 2. Functional Requirements

### Game Core
- [ ] Player can start a new game session without logging in (guest mode, score not persisted)
- [ ] Authenticated players have scores and history persisted
- [ ] Each session consists of 10 questions
- [ ] Question types: Character Guess, Movie Match, Quote Detective, Scene Rewind
- [ ] Each question has exactly 4 answer choices (1 correct + 3 distractors)
- [ ] Questions are sourced from TMDB media; prompts generated by GPT-4o
- [ ] Each question has a 10-second timer; unanswered = wrong
- [ ] Hints available (2 per session); each hint eliminates 1 wrong answer
- [ ] Score = base_points × speed_multiplier × difficulty_multiplier

### Difficulty Adaptation
- [ ] Starting difficulty: 2 (out of 5) for new players; resume last known level for returning players
- [ ] After every 5 questions, recalculate difficulty using ELO-lite: correct answers push difficulty up, incorrect push it down
- [ ] Difficulty affects: obscurity of chosen media, complexity of GPT-4o prompt, number of decoy distractors from same franchise

### Daily Challenge
- [ ] One challenge published per UTC day, identical questions for all players
- [ ] 12 questions (10 seeded + 2 AI-generated at generation time)
- [ ] One submission per user per day (409 on re-submit)
- [ ] Daily leaderboard resets at 00:00 UTC

### Leaderboard
- [ ] Global all-time top 100 (by total cumulative score)
- [ ] Daily leaderboard (by daily challenge score, tie-break by time-to-complete ascending)
- [ ] Players can see their own rank even if outside top 100

### User Accounts
- [ ] Register with email + username + password
- [ ] Login / logout / refresh token
- [ ] Profile page: total games, total score, average accuracy, personal best, recent games

---

## 3. Non-Functional Requirements

- [ ] API p95 latency < 500ms under 100 concurrent users
- [ ] GPT-4o question generation < 3s (stream response to client if > 1s)
- [ ] TMDB API rate limit: max 40 requests / 10 seconds (enforced in service layer)
- [ ] 99.5% uptime (single-region, no SLA initially)
- [ ] Passwords hashed with bcrypt, cost factor 12
- [ ] JWTs expire: access 15m, refresh 7d
- [ ] All inputs validated with Zod before hitting business logic
- [ ] No PII logged beyond hashed user ID

## 5. API Design

### Game Endpoints
```
POST   /api/game/start                    → { sessionId, question, hintsRemaining }
POST   /api/game/:sessionId/answer        → { correct, pointsAwarded, score, streak, nextQuestion | gameOver }
GET    /api/game/:sessionId/status        → { score, streak, difficulty, hintsRemaining, questionIndex }
POST   /api/game/:sessionId/hint          → { hint, hintsRemaining }
```

### Auth Endpoints
```
POST   /api/auth/register                 → { user, accessToken, refreshToken }
POST   /api/auth/login                    → { user, accessToken, refreshToken }
POST   /api/auth/refresh                  → { accessToken }
POST   /api/auth/logout                   → 204
```

### Leaderboard Endpoints
```
GET    /api/leaderboard?page=1&limit=20   → { entries[], total, userRank? }
GET    /api/leaderboard/daily             → { entries[], date, userRank? }
```

### Daily Challenge Endpoints
```
GET    /api/challenge/today               → { challengeDate, question (first), hintsRemaining }
POST   /api/challenge/today/submit        → { score, rank, leaderboard[] }
```

### User Endpoints
```
GET    /api/users/me                      → { user, stats }
GET    /api/users/me/history?page=1       → { sessions[] }
```

## 6. GPT-4o Question Generation

### System Prompt Strategy
The GPT-4o call receives:
- Media title, year, genre tags, character names, notable quotes (from TMDB)
- Target question type and difficulty level
- JSON schema for structured output

### Structured Output Schema
```json
{
  "type": "object",
  "required": ["questionType", "prompt", "correctAnswer", "distractors", "hint", "difficulty"],
  "properties": {
    "questionType": { "type": "string", "enum": ["character", "movie", "quote", "scene"] },
    "prompt":       { "type": "string" },
    "correctAnswer":{ "type": "string" },
    "distractors":  { "type": "array", "items": { "type": "string" }, "minItems": 3, "maxItems": 3 },
    "hint":         { "type": "string" },
    "difficulty":   { "type": "integer", "minimum": 1, "maximum": 5 }
  }
}
```

### Difficulty Guidelines for GPT-4o Prompt
| Difficulty | Instruction to Model |
|------------|----------------------|
| 1          | Use the most iconic, globally recognizable characters. Distractors from completely different genres. |
| 2          | Well-known characters. Distractors from same genre but different franchise. |
| 3          | Supporting characters or less-quoted lines. Distractors from same franchise. |
| 4          | Minor characters or obscure quotes. Distractors could be plausible confusions. |
| 5          | Deep-cut trivia: character actors, one-scene roles, paraphrased quotes. All distractors are highly plausible. |

## 7. Scoring Algorithm

```
base_points = 100

speed_multiplier:
  answered in 0–3s   → 2.0×
  answered in 3–6s   → 1.5×
  answered in 6–9s   → 1.0×
  answered in 9–10s  → 0.75×
  timed out (>10s)   → 0×

difficulty_multiplier:
  level 1 → 0.5×
  level 2 → 0.75×
  level 3 → 1.0×
  level 4 → 1.5×
  level 5 → 2.0×

streak_bonus: +10 per consecutive correct answer beyond 2

final_score = floor(base_points × speed_multiplier × difficulty_multiplier) + streak_bonus
```

## 8. Test Plan

### Unit Tests
- `ScoreService.calculate()` — all speed/difficulty/streak combinations
- `DifficultyService.adjust()` — edge cases: already at max (5), already at min (1)
- `QuestionGeneratorService.generate()` — mocked OpenAI, valid schema returned
- `QuestionGeneratorService.generate()` — OpenAI timeout → fallback to seeded bank
- `TMDBService.getMedia()` — mocked HTTP, normalized `MediaItem` returned
- Zod schema validation: all request bodies (missing fields, wrong types)

### Integration Tests (Supertest)
- Full auth flow: register → login → refresh → logout
- Full game flow: start → answer (correct) → answer (incorrect) → hint → game over
- Score persists after completing session
- Daily challenge: two users get same question set on same day
- Leaderboard: sorted correctly after multiple submissions

### Edge Cases
- Guest user completes game — score not persisted, no 500 error
- Player uses both hints — third hint request returns 402
- Session expires mid-game — any subsequent answer request returns 410
- TMDB API unreachable — game falls back to pre-seeded question bank (no 500)
- OpenAI API unreachable — game falls back to pre-seeded question bank (no 500)
- Daily challenge resubmission — 409 returned
